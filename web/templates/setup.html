WELCOME TO SETUP

Five quick steps and your console is live. Each step saves as soon as you continue — you can always come back and fix details later.

Step 1: Admin Account
Step 1: Create Your Admin Account

This account gives you full access to the dashboard. There are no default logins — you choose the credentials.

Step 2: Connect to Nuki Web API

To monitor your lock, we need a Nuki Web API token. This is what lets the console see lock events.

How to get your token (2 minutes)
  1. Open the Nuki Web Dashboard and sign in with your Nuki account.
  2. Click your account icon → API (or go directly to web.nuki.io › Settings › API).
  3. Click Generate API token. Give it a name like "Nuki Console".
  4. Under Permissions / Scopes, select only read scopes (read smartlock state, read activity logs). A scoped, read-only token is the most secure choice — it is the least-privilege option Nuki offers and all this console needs for monitoring.
  5. Copy the token and paste it below. It looks like a long random string of letters and numbers.
The token is validated the moment you continue — a typo is caught here, not later. It is stored only in config/credentials.ini on your own machine.
Optional now — you can skip and add it later in Configuration.
Step 3: Telegram Notifications Optional

Get instant alerts on your phone via Telegram. Skipping is fine — you can add it any time in Notifications settings.

What is this? A bot token, from @BotFather
  1. In Telegram, open @BotFather (the official bot-creation bot).
  2. Send /newbot and follow the prompts (name and username).
  3. BotFather replies with a token like 123456789:AAH39sk... — paste it below.
Anyone with this token can control your bot — keep it secret.
Where to find your Chat ID
  1. Press Start in your new bot's chat — a bot can only message people who contacted it first.
  2. Message @userinfobot and it replies with your numeric Id.
  3. Enter that number below. For a group, add the bot to the group and use the group's (negative) ID.
Alternatively, after setup: docker exec -it nuki python scripts/get_telegram_chat_id.py

An app password, not your normal password

Most providers no longer allow apps to log in with your regular password. Generate a dedicated one:

  • Gmail: enable 2-Step Verification, then create one at myaccount.google.com/apppasswords.
  • Outlook / Microsoft 365: app password from your Microsoft account security settings.
  • Purelymail: manage credentials in the Purelymail web portal under account settings.
  • Other providers: look for "app password" or "SMTP password" in their security settings.
